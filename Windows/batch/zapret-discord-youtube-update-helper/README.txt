Этот .bat-скрипт помогает быстро и безопасно обновить zapret-discord-youtube (далее просто «запрет»).

В коде оставлены подробные комментарии — можете открыть скрипт в Блокноте и убедиться, что он ничего подозрительного не делает с вашими данными.

Что и в каком порядке нужно сделать один раз

1. (Очень желательно) Обновить список блокировок  
   Рядом со скриптом лежит файл general-upd.txt (по умолчанию пустой).  
   Если хотите добавить свои правила или правила для конкретных игр/программ —  
   откройте нужные файлы из этой же папки > скопируйте их содержимое > вставьте в general-upd.txt.

2. Указать свою папку с запретом  
   Откройте скрипт в любом текстовом редакторе (Блокнот, Notepad++, VS Code и т.д.)  
   и найдите этот блок:

   :: ================================================
   :: 3. УКАЖИТЕ СВОЙ ПУТЬ К ПАПКЕ zdy
   :: ================================================
   set "ZDY_PATH=Диск:\Путь\К\Твоей\Папке\zdy"     ::  измените эту строку

   Замените строку на свой реальный путь, например:
   set "ZDY_PATH=D:\Programs\zapret"
   set "ZDY_PATH=C:\Users\ВашеИмя\zapret"
   Название папки может быть любым — zdy, zapret, block и т.д.

3. Проверить/установить 7-Zip (нужен для распаковки архива)
   Скрипт ищет 7-Zip в стандартных местах:
   C:\Program Files\7-Zip\7z.exe
   C:\Program Files (x86)\7-Zip\7z.exe
   Если у вас 7-Zip стоит в другом месте или вообще не установлен —
   либо установите его с официального сайта,
   либо укажите свой путь в скрипте в этом блоке:
:: ================================================
:: 6. Распаковка архива в zdy (нужен 7-Zip)
:: ================================================
:: 6.1 Обновите путь, если 7-Zip не находится в стандартном месте
:: ================================================
      set "SEVENZIP=Диск:\Ваш\Путь\К\7-Zip\7z.exe" :: ваш путь к 7-Zip

4. Как пользоваться дальше (каждый раз при обновлении)
   1. Скачайте свежий архив zapret-discord-youtube-*.rar > положите его в папку Загрузки
   2. (по желанию) добавьте новые правила в general-upd.txt, как описано выше
   3. Щёлкните правой кнопкой мыши по файлу скрипта → «Запуск от имени администратора»

Скрипт сделает всё сам:
* остановит и удалит старый Windivert
* полностью очистит вашу папку с запретом
* найдёт самый свежий архив в Загрузках
* распакует его в указанную папку
* допишет содержимое general-upd.txt в конец файла lists/list-general.txt

Готово!
